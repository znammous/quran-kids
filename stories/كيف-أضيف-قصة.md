# كيف أُضيف قصّة

القصصُ محتوًى على الشبكة لا داخل التطبيق: تُضاف بملفَّين ورفعٍ إلى GitHub،
وتصل إلى الأطفال خلال دقائق — **بلا تحديثٍ للتطبيق في المتاجر**.

---

## ١) المقاسات

### الصور

| | |
|---|---|
| **النسبة** | ١٦:٩ أفقيّة — تُنشر واسعةً وتُقصّ عند العرض |
| **المقاس** | **١٦٠٠ × ٩٠٠** بكسل |
| **الأدنى المقبول** | ١٠٦٤ × ٥٩٢ |
| **الصيغة** | WebP (أو SVG للرسم المتّجه، أو PNG) |
| **الحجم** | دون ١٥٠ كيلوبايت للصورة |

**الصورةُ الواحدةُ تُعرض في موضعين، ولكلٍّ قصُّه:**

| | ما يُرى |
|---|---|
| **في الصفحة** | نافذةُ ٤:٣ من وسطها — يذهب نحوُ ١٢٪ من كلّ جانب |
| **عند التكبير** (زرُّ 🔍) | مُدارةً ملءَ الشاشة — يذهب نحوُ ٩٪ من أعلاها ومثلُه من أسفلها |

فلا تضعْ شيئاً مهمّاً عند حافّةٍ من الحوافّ الأربع. وإن وقع أهلُ المشهد
إلى جانبٍ فزحزحْ نافذةَ الصفحة بـ`pos` (انظر أدناه)، ولا تُعاد الصورة.

ولِمَ ١٦:٩ والإطارُ ٤:٣؟ لأنّ المكبِّرَ يُدير الصورةَ، والشاشةُ مُدارةً
تطلب نسبةً نحوَ ٢٫١٦:١. فالواسعةُ تملؤها بقصّ ١٨٪، ونسخةُ ٤:٣ لا تملؤها
إلّا بقصّ ٣٨٪ — يذهب فيه رأسُ الجبل ومرجُ الزهر.

### ما يُرسم

- **حجابُ المرأة البالغة خارج بيتها يستر الشعرَ كلَّه**: لا مقدّمةَ شعرٍ ولا
  خصلة، والرقبةُ مستورة — في الساحة والطريق وأمام الباب، وللكومبارس في
  الخلفيّة كما للشخصيّة. والبناتُ الصغيرات لا تشملهنّ.
  ونماذجُ الصور تُظهر مقدّمةَ الشعر من تلقاء نفسها، فاكتبْها صريحةً في وصف
  كلّ صورة، وافحصْ الصورةَ مكبَّرةً قبل رفعها.

- **الأنبياءُ والرسلُ لا يُرسمون بأيّ صورة**: لا وجهاً، ولا من الخلف، ولا
  بثوبٍ يستر الوجه، ولا ظلّاً، ولا صغاراً من بعيد — يغيبون عن الصورة تماماً،
  ويُرسم قومُهم ومكانُهم. فإن خاطبهم القومُ نظروا وأشاروا إلى خارج الإطار.

### الغلاف

غلافان لكلّ قصّة:

| | المقاس | أين يظهر |
|---|---|---|
| **العريض** `cw` | **٤٨٠ × ٣٦٠** (٤:٣)، دون ٤٠ كيلوبايت | رأسُ البطاقة في قائمة القصص — عمودان، والصورةُ أكبرُ ما فيها |
| **المربّع** `cover` | **٢٠٠ × ٢٠٠** | بشارةُ القصّة الجديدة، وبديلُ العريض إن غاب |

يُقصّان من صورة صفحةٍ واحدةٍ فيها أهلُ القصّة، والعريضُ ملءُ ارتفاعها أو قريبٌ منه.

### النصّ

| | |
|---|---|
| **الأفضل** | **١٢٠ – ١٨٠ حرفاً** للصفحة (٢٠ – ٣٠ كلمة) |
| **الأقصى بلا تمرير** | ٤٦٥ حرفاً (٨٠ كلمة) على الهواتف الحديثة |
| | لكنّ الهاتفَ الصغير (٣٦٠×٦٤٠) لا يسع إلّا **١٨٦ حرفاً** |

فمن التزم ١٨٠ حرفاً لم يحتج طفلٌ إلى تمرير النصّ على أيّ جهاز. وما زاد
يُمرَّر في صندوقه — لا تتحرّك الصفحةُ ولا يغيب الزرّان.

وفصْلُ الفقرات بسطرٍ فارغ (`\n\n`) أريحُ للعين.

## ٢) الملفّات

```
stories/index.json          ← الفهرس: سطرٌ لكلّ قصّة
stories/s/<المعرّف>.json     ← القصّة: صفحاتُها
stories/img/<المعرّف>-N.webp ← صورةُ كلّ صفحة
stories/covers/<المعرّف>.webp ← الغلاف المربّع
stories/covers/w/<المعرّف>.webp ← الغلاف العريض
```

### الفهرس — `index.json`

```json
{
  "v": 2,
  "stories": [
    {
      "id": "kahf",
      "t": "أصحاب الكهف",
      "d": "فتيةٌ آمنوا بربّهم فزادهم هدى",
      "k": ["sabr", "iman"],
      "ic": "🏔️",
      "cover": "covers/kahf.webp",
      "file": "s/kahf.json",
      "rev": 4,
      "added": "2026-09-19"
    }
  ]
}
```

| الحقل | معناه |
|---|---|
| `id` | معرّفٌ لا يتكرّر ولا يتغيّر — به يعرف التطبيقُ الجديدَ من القديم |
| `t` | العنوان |
| `d` | سطرٌ يصفها في القائمة وفي شاشة البشارة |
| `ic` | إيموجي يقوم مقام الغلاف إن لم يكن ثمّة غلاف |
| `cover` | مسارُ الغلاف المربّع (اختياريّ) |
| `cw` | مسارُ الغلاف العريض ٤:٣ لبطاقة القائمة (اختياريّ) |
| `file` | مسارُ ملفّ القصّة |
| `rev` | رقمُ المراجعة (اختياريّ، الأصلُ ١) — **ارفعْه كلّما بدّلتَ قصّةً بمعرّفها** |
| `added` | تاريخُ الإضافة (للتوثيق) |
| `k` | **القيمُ التي تعالجها القصّة** — واحدةٌ أو أكثر، بها يصفّي وليُّ الأمر القائمة («😤 الغضب والخصام» مثلاً) |

### القيم — `k`

أزرارٌ فوق قائمة القصص، يختار منها وليُّ الأمر ما يريد أن يعالجه فتظهر قصصُه وحدَها.
والقيمةُ تُكتب في `k` بمعرّفها، ومعرّفاتُها في `ST_KINDS` بـindex.html:

| المعرّف | القيمة | المعرّف | القيمة |
|---|---|---|---|
| `ghadab` | 😤 الغضب والخصام | `rahma` | 💞 الرحمة والرفق |
| `lisan` | 🗣️ حفظ اللسان | `awn` | 🧱 التعاون وعون الناس |
| `sidq` | 🤝 الصدق والأمانة | `sabr` | ⏳ الصبر والثبات |
| `adl` | ⚖️ العدل | `shaja` | 🦁 الشجاعة وقول الحقّ |
| `hasad` | 💚 الحسد وحبّ الخير للغير | `iman` | 🕋 الإيمان والتوكّل |
| `kibr` | 🌱 التواضع وترك الكِبر | `taa` | 🤲 الطاعة والإخلاص والتوبة |
| `shukr` | 🙏 الشكر والقناعة | `adab` | 🚪 الآداب |
| `karam` | 🎁 الكرم والعطاء | `nizam` | ⏰ الوقت والإتقان والنظام |
| `birr` | 👪 برّ الوالدين والأهل | | |

لا تُعطِ القصّةَ إلّا ما تعالجه حقّاً — اثنتان أو ثلاثٌ تكفي، فالتصفيةُ تفقد معناها إن
ظهرت القصّةُ تحت كلّ شيء. وقيمةٌ جديدةٌ تُضاف إلى `ST_KINDS` وتُترجم في `lang/*.js`.

### فهرسُ البحث — `q.json`

البحثُ في القصص يشمل نصَّ صفحاتها، والقصّةُ لا تُنزَّل إلّا حين تُفتح — فنصوصُها كلُّها
في `stories/q.json` (ومترجمُها `stories/<لغة>/q.json`)، يُجلب عند أوّل بحث. **لا يُكتب
باليد**: بعد كلّ قصّةٍ تُضاف أو تُعدَّل أو تُترجم

```bash
npm run stories
```

و`npm run i18n` ينبّه إن نُسي. والتطبيقُ يجلب الجديدَ منه برقم الفهرس `v`، فلا تنسَ رفعه.

### صفحاتُ المشاركة — `p/` و`og/`

زرُّ 📤 في القصّة يشارك رابطَ صفحتها `stories/p/<المعرّف>.html` (والمترجمةُ
`stories/<لغة>/p/<المعرّف>.html`). فيها وسومُ og، فيعرض واتساب وتيليجرام وغيرُهما
**غلافَها العريض وعنوانَها ووصفَها** معاينةً، ومن فتحها نُقل إلى القصّة في التطبيق
(`index.html#story=<المعرّف>`) — ومن يفتحه أوّلَ مرّةٍ يقرؤها ثمّ يمرّ بالمعالج.

وصورةُ المعاينة `stories/og/<المعرّف>.jpg` من الغلاف العريض (`cw`) — فـWebP لا تقرؤه
كلُّ التطبيقات. والكلُّ يكتبه `npm run stories` نفسُه (والصورةُ بـsips على ماك)، فلا شيءَ يُكتب باليد.

**و`rev` ليس توثيقاً بل ضرورة**: مخزنُ القصص في الجهاز يسبق الشبكةَ عمداً
— إذِ القصّةُ لا تتغيّر بعد نشرها في الأصل — والفهرسُ وحدَه يُسأل عنه كلَّ
مرّة. فلولا رفعُ `rev` بقي من قرأ القصّةَ على نسختها القديمة أبداً وهو لا
يدري. ورفعُه يحمل الرقمَ في روابط القصّة كلِّها — ملفِّها وغلافِها وصورِ
صفحاتها — ويُعيد إعلانَها «✨ قصّةٌ تجدّدت» لمن قرأ ما قبلها. والمحرّرُ
يرفعه من تلقاء نفسه حين تحفظ قصّةً موجودة.

**ارفعْ `v` مع كلّ تعديل** — رقمٌ للتوثيق لا أكثر، لكنّه يُعينك على التتبّع.

### القصّة — `s/<المعرّف>.json`

```json
{
  "id": "kahf",
  "t": "أصحاب الكهف",
  "pages": [
    { "img": "img/kahf-1.webp", "x": "نصُّ الصفحة الأولى.\n\nفقرةٌ ثانية.", "pos": "96%" },
    { "img": "img/kahf-2.webp", "x": "نصُّ الصفحة الثانية." }
  ]
}
```

`img` اختياريّ — صفحةٌ بلا صورةٍ تعرض نصَّها وحده. و`x` هو النصّ.

و`pos` اختياريّ كذلك: موضعُ نافذة ٤:٣ أفقيّاً في الصورة الواسعة — `0%`
أقصى اليسار، و`50%` الوسطُ وهو الأصل، و`100%` أقصى اليمين. لا تكتبه إلّا
حين يخرج شيءٌ مهمٌّ عن النافذة الوسطى.

> **مثال**: في المشهد الأوّل من «أصحاب الكهف» يقف الفتيةُ إلى يمين اللقطة،
> فالنافذةُ الوسطى تقطع سابعَهم نصفَين — و`"pos": "96%"` تُزحزحها إليهم.

## ٤) ما يجري تلقائيّاً

- **بشارةٌ بشاشة الحماسة** عند أوّل فتحٍ بعد وصولها: أيقونتُها واسمُها ووصفُها.
- **نقطةٌ حمراء** على زرّ 🎪 المغامرة وعلى تبويب القصص وعلى بطاقتها، حتى يفتحها.
- **تُحفظ في الجهاز** عند أوّل فتح، فتُقرأ بعدها بلا إنترنت للأبد.
- ولا تُنزَّل القصّةُ إلّا حين يضغطها الطفل — الفهرسُ وحدَه هو الذي يُجلب عند
  كلّ فتحٍ للتطبيق، وهو كيلوباتٌ لا أكثر.

> **تنبيه**: القصصُ لا تمرّ على مراجعة المتاجر، فملاءمتُها للأطفال مسؤوليّتُك
> وحدك. واحرصْ على حقوق الرسوم — لا تنشر ما لا تملكه.

## وقفةٌ لوليّ الأمر (اختياريّة)

بطاقةٌ للكبير تُفتح بزرٍّ تحت آخر صفحة: `stories/n/<المعرّف>.json` ‏(`{"id", "n", "note"}`)، ويُكتب `"n": 1` في سطر القصّة
بالفهرس. وتُرفع `n` مع كلّ تعديلٍ للوقفة (لا `rev` — فالقصّةُ لا تصير «جديدة» ولا تسقط ترجماتُها).

نصُّها ثلاثة أقسام، كلٌّ بعنوانٍ بين `**…**`:
- **معنى الحديث / معنى الآية**: منقولٌ بنصّه مع مصدره — الحديثُ من شرح «الدرر السنيّة» (dorar.net) ولا يُورَد إلّا صحيحٌ
  أو حسن، والآيةُ من «التفسير الميسّر» (data/tafsir) — ثمّ سطرُ «📖 المصدر».
- **حاوِرْ طفلك**: ثلاثةُ أسئلةٍ عن أحداث القصّة، وما يُخشى أن يُفهم خطأً يُبيَّن في جوابٍ بين قوسين.
- **تمرينُ الأسبوع**: عملٌ صغيرٌ يُجرَّب في البيت.
