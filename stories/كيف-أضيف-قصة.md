# كيف أُضيف قصّة

القصصُ محتوًى على الشبكة لا داخل التطبيق: تُضاف بملفَّين ورفعٍ إلى GitHub،
وتصل إلى الأطفال خلال دقائق — **بلا تحديثٍ للتطبيق في المتاجر**.

---

## ١) المقاسات

### الصور

| | |
|---|---|
| **النسبة** | ١٦:٩ أفقيّة — تُنشر واسعةً وتُقصّ عند العرض |
| **المقاس** | **١٦٠٠ × ٩٠٠** بكسل |
| **الأدنى المقبول** | ١٠٦٤ × ٥٩٢ |
| **الصيغة** | WebP (أو SVG للرسم المتّجه، أو PNG) |
| **الحجم** | دون ١٥٠ كيلوبايت للصورة |

**الصورةُ الواحدةُ تُعرض في موضعين، ولكلٍّ قصُّه:**

| | ما يُرى |
|---|---|
| **في الصفحة** | نافذةُ ٤:٣ من وسطها — يذهب نحوُ ١٢٪ من كلّ جانب |
| **عند التكبير** (زرُّ 🔍) | مُدارةً ملءَ الشاشة — يذهب نحوُ ٩٪ من أعلاها ومثلُه من أسفلها |

فلا تضعْ شيئاً مهمّاً عند حافّةٍ من الحوافّ الأربع. وإن وقع أهلُ المشهد
إلى جانبٍ فزحزحْ نافذةَ الصفحة بـ`pos` (انظر أدناه)، ولا تُعاد الصورة.

ولِمَ ١٦:٩ والإطارُ ٤:٣؟ لأنّ المكبِّرَ يُدير الصورةَ، والشاشةُ مُدارةً
تطلب نسبةً نحوَ ٢٫١٦:١. فالواسعةُ تملؤها بقصّ ١٨٪، ونسخةُ ٤:٣ لا تملؤها
إلّا بقصّ ٣٨٪ — يذهب فيه رأسُ الجبل ومرجُ الزهر.

### الغلاف

مربّعٌ **٢٠٠ × ٢٠٠** بكسل — يظهر صغيراً في قائمة القصص.

### النصّ

| | |
|---|---|
| **الأفضل** | **١٢٠ – ١٨٠ حرفاً** للصفحة (٢٠ – ٣٠ كلمة) |
| **الأقصى بلا تمرير** | ٤٦٥ حرفاً (٨٠ كلمة) على الهواتف الحديثة |
| | لكنّ الهاتفَ الصغير (٣٦٠×٦٤٠) لا يسع إلّا **١٨٦ حرفاً** |

فمن التزم ١٨٠ حرفاً لم يحتج طفلٌ إلى تمرير النصّ على أيّ جهاز. وما زاد
يُمرَّر في صندوقه — لا تتحرّك الصفحةُ ولا يغيب الزرّان.

وفصْلُ الفقرات بسطرٍ فارغ (`\n\n`) أريحُ للعين.

## ٢) الملفّات

```
stories/index.json          ← الفهرس: سطرٌ لكلّ قصّة
stories/s/<المعرّف>.json     ← القصّة: صفحاتُها
stories/img/<المعرّف>-N.webp ← صورةُ كلّ صفحة
stories/covers/<المعرّف>.webp ← الغلاف
```

### الفهرس — `index.json`

```json
{
  "v": 2,
  "stories": [
    {
      "id": "kahf",
      "t": "أصحاب الكهف",
      "d": "فتيةٌ آمنوا بربّهم فزادهم هدى",
      "ic": "🏔️",
      "cover": "covers/kahf.webp",
      "file": "s/kahf.json",
      "rev": 4,
      "added": "2026-09-19"
    }
  ]
}
```

| الحقل | معناه |
|---|---|
| `id` | معرّفٌ لا يتكرّر ولا يتغيّر — به يعرف التطبيقُ الجديدَ من القديم |
| `t` | العنوان |
| `d` | سطرٌ يصفها في القائمة وفي شاشة البشارة |
| `ic` | إيموجي يقوم مقام الغلاف إن لم يكن ثمّة غلاف |
| `cover` | مسارُ الغلاف (اختياريّ) |
| `file` | مسارُ ملفّ القصّة |
| `rev` | رقمُ المراجعة (اختياريّ، الأصلُ ١) — **ارفعْه كلّما بدّلتَ قصّةً بمعرّفها** |
| `added` | تاريخُ الإضافة (للتوثيق) |

**و`rev` ليس توثيقاً بل ضرورة**: مخزنُ القصص في الجهاز يسبق الشبكةَ عمداً
— إذِ القصّةُ لا تتغيّر بعد نشرها في الأصل — والفهرسُ وحدَه يُسأل عنه كلَّ
مرّة. فلولا رفعُ `rev` بقي من قرأ القصّةَ على نسختها القديمة أبداً وهو لا
يدري. ورفعُه يحمل الرقمَ في روابط القصّة كلِّها — ملفِّها وغلافِها وصورِ
صفحاتها — ويُعيد إعلانَها «✨ قصّةٌ تجدّدت» لمن قرأ ما قبلها. والمحرّرُ
يرفعه من تلقاء نفسه حين تحفظ قصّةً موجودة.

**ارفعْ `v` مع كلّ تعديل** — رقمٌ للتوثيق لا أكثر، لكنّه يُعينك على التتبّع.

### القصّة — `s/<المعرّف>.json`

```json
{
  "id": "kahf",
  "t": "أصحاب الكهف",
  "pages": [
    { "img": "img/kahf-1.webp", "x": "نصُّ الصفحة الأولى.\n\nفقرةٌ ثانية.", "pos": "96%" },
    { "img": "img/kahf-2.webp", "x": "نصُّ الصفحة الثانية." }
  ]
}
```

`img` اختياريّ — صفحةٌ بلا صورةٍ تعرض نصَّها وحده. و`x` هو النصّ.

و`pos` اختياريّ كذلك: موضعُ نافذة ٤:٣ أفقيّاً في الصورة الواسعة — `0%`
أقصى اليسار، و`50%` الوسطُ وهو الأصل، و`100%` أقصى اليمين. لا تكتبه إلّا
حين يخرج شيءٌ مهمٌّ عن النافذة الوسطى.

> **مثال**: في المشهد الأوّل من «أصحاب الكهف» يقف الفتيةُ إلى يمين اللقطة،
> فالنافذةُ الوسطى تقطع سابعَهم نصفَين — و`"pos": "96%"` تُزحزحها إليهم.

## ٣) الرفع

```bash
git add stories/
git commit -m "📖 قصّة جديدة: <العنوان>"
git push origin main
```

تظهر عند الأطفال خلال دقائق من رفعها.

## ٤) ما يجري تلقائيّاً

- **بشارةٌ بشاشة الحماسة** عند أوّل فتحٍ بعد وصولها: أيقونتُها واسمُها ووصفُها.
- **نقطةٌ حمراء** على زرّ 🎪 المغامرة وعلى تبويب القصص وعلى بطاقتها، حتى يفتحها.
- **تُحفظ في الجهاز** عند أوّل فتح، فتُقرأ بعدها بلا إنترنت للأبد.
- ولا تُنزَّل القصّةُ إلّا حين يضغطها الطفل — الفهرسُ وحدَه هو الذي يُجلب عند
  كلّ فتحٍ للتطبيق، وهو كيلوباتٌ لا أكثر.

> **تنبيه**: القصصُ لا تمرّ على مراجعة المتاجر، فملاءمتُها للأطفال مسؤوليّتُك
> وحدك. واحرصْ على حقوق الرسوم — لا تنشر ما لا تملكه.
