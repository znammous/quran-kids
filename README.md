# نور الوحي

لعبة تفاعلية لتحفيظ القرآن الكريم للأطفال — صفحة واحدة مستقلة تعمل في المتصفح
بلا إنترنت وبلا تثبيت.

## التشغيل على الإنترنت

الموقع منشور عبر GitHub Pages (الرابط في وصف المستودع).

## التشغيل محليًا

انقر نقرًا مزدوجًا على **`شغّل-اللعبة.bat`**.

يشغّل هذا خادمًا محليًا على `http://127.0.0.1:8731/` ويفتح اللعبة. الخادم ضروري
لخاصية تسجيل الصوت فقط: المتصفحات تمنع الميكروفون في صفحات `file://` لأنها لا
تُعدّ سياقًا آمنًا. بقية اللعبة تعمل بفتح `index.html` مباشرة.

يتطلب الخادم المحلي تثبيت Python من [python.org](https://python.org).

## الملفات

| الملف | الوصف |
|---|---|
| `index.html` | اللعبة كاملة (مستقلة، بلا موارد خارجية) |
| `games.html` | مجموعة الألعاب التعليمية |
| `start.html` | صفحة تحويل إلى اللعبة |
| `run.bat` | تشغيل الخادم المحلي |
| `شغّل-اللعبة.bat` | اختصار عربي لـ `run.bat` |
| `اقرأني-نور-الوحي.txt` | دليل الاستخدام التفصيلي |

> ملفات الخطط بصيغة PDF غير مرفوعة في المستودع لكبر حجمها (‏~74 م.ب).
