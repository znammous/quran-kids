# صورُ المتجر ونصوصُه بكلّ لغة

النصوص: `store/l10n/<رمز>/listing.json` (المصدر) و`listing.md` (للنسخ في App Store Connect وGoogle Play، وتحت كلّ حقلٍ عددُ حروفه وحدُّه).

الصور تُولَّد ولا تُرفع إلى المستودع (نحو ٩ ميغا لكلّ لغة):

```
npm i --no-save playwright                     # مرّةً واحدة، ويحتاج Chrome
python3 -m http.server 8765 &                  # من جذر المستودع: الأداةُ تفتح التطبيقَ منه
node scripts/store/capture.cjs <رمز> phone     # ٨ مشاهد من حسابٍ مزروع (seed_db.json) ← store/l10n/_raw
node scripts/store/capture.cjs <رمز> ipad
node scripts/store/compose.cjs <رمز>           # يؤطّرها بعناوين listing.json ← store/l10n/<رمز>/
```

الناتج في `store/l10n/<رمز>/`:
- `appstore/iphone-6.9` (1290×2796) و`iphone-6.5` (1284×2778) و`ipad-13` (2048×2732)
- `play/phone` (1080×1920) و`play/feature-1024x500.jpg`

المشاهد: 1-path، 2-games، 3-seg، 4-rec، 5-mean، 6-build، 7-words، 8-board — وعناوينُها في `screens` من listing.json.
في لغات اليسار يصير اسما الطفلين Maryam وOmar. والعنوانُ الطويل يُصغَّر تلقائيّاً حتى يسعه السطر.
