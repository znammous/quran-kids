# لغاتُ الواجهة

الأزرارُ والرسائلُ وحدَها تُترجم. **المصحفُ والآياتُ والتفسيرُ والغريبُ والقصصُ تبقى عربيّةً دائماً.**
وأسماءُ السور والقرّاء عربيّةٌ في لغات اليمين، وبالحروف اللاتينيّة في لغات اليسار (من حقل `en` في SURAHS).

**اللغاتُ الآن** (كلُّها ظاهرةٌ في «📱 الجهاز ← 🌐 اللغة» — قرار صاحب التطبيق: كلُّ لغةٍ تُضاف تظهر فوراً):

| الرمز | الاتّجاه | ترجمةُ المعاني (QuranEnc) |
|---|---|---|
| ur | يمين | `urdu_junagarhi` (رواد) |
| ps | يمين | `pashto_rwwad` |
| en | يسار | `english_rwwad` |
| id | يسار | `indonesian_complex` (نسخة مجمع الملك فهد) |
| ms | يسار | **لا ترجمة**: `malay_basumayyah` تؤوّل الصفات، فيُعرض التفسيرُ الميسّر العربيّ |
| bn | يسار | `bengali_rwwad` (غيرُ مُدرَجةٍ في قائمة الـ API ورقمُ إصدارها لا يظهر) |
| tr | يسار | `turkish_rwwad` |
| fa | يمين | `persian_ih` (رواد) — فارسيّةٌ تُفهم في أفغانستان، والدريّةُ مقدَّمةٌ عند الخلاف |
| fr | يسار | `french_rashid` (رشيد معاش، بإشراف رواد) |
| sw | يسار | `swahili_rwwad` |
| ha | يسار | `hausa_gummi` (أبو بكر جومي) |
| uz | يسار | `uzbek_rwwad` — كيريليّة، تُحوَّل إلى اللاتينيّة |
| so | يسار | `somali_yacob` — يُحذف رقمُ الآية من أوّلها |

والتاريخُ الهجريُّ في الرئيسية هجريٌّ في كلّ لغة (طلبُ صاحب التطبيق)؛ ولغةٌ لا تقويمَ هجريّاً لها في المتصفّح
تُعرض بالإنجليزيّة (`hijriDate` يفحص التقويمَ الفعليّ).
ولغيرِ العربيّة تُعرض في لوحة «💡 المعاني» ترجمةُ معاني الآية كاملةً بلغته (لا معاني الكلمات).

## كيف يعمل

- **المحرّك** في رأس `index.html` (`NUR_I18N`): يراقب الصفحة، وكلُّ نصٍّ عربيٍّ يظهر يُبحث عنه في القاموس ويُستبدل.
  والعربيّةُ لا تُحمِّل شيئاً ولا تراقب شيئاً.
- **القاموس** `lang/<رمز>.js`: مفتاحُه **النصُّ العربيُّ كما يظهر**، وقيمتُه ترجمتُه. ما ليس فيه يظهر بعربيّته فلا ينكسر شيء.
- **ما يبحث به المحرّك**، بالترتيب:
  1. النصُّ كاملاً.
  2. بلا رموزٍ في أوّله وآخره: «⚙️ الإعدادات» ← «الإعدادات».
  3. الأرقامُ خانات: «الآية 5» ← «الآية {0}».
  4. أسماءُ السور خانات: «من الفلق» ← «من {s1}» (عربيّةٌ في لغات اليمين، لاتينيّةٌ في لغات اليسار).
  5. المقطَّع: «… — …» يُترجم إن تُرجمت أجزاؤه كلُّها، و«… • …» جزءاً جزءاً.
  6. الجملةُ التي فيها `<b>` أو `<br>` أو `<small>` تُترجم كاملةً **بوسومها** (مفتاحُها HTML كما تكتبه الصفحة وقتَ العرض).
- **صيغُ العدد**: `arCount/arYears/arMonths/arDays/marra/agoText` تسأل القاموس أوّلاً عن `#1 <مفرد>` و`#n <مفرد>`
  (مثل `"#n صفحة واحدة": "{n} صفحات"`). وكلُّ مصفوفة `C_*` جديدة تحتاج هذين المفتاحين في كلّ قاموس.
- **`tx('قالب {x}', {x:…})`** في الشيفرة: لجملةٍ تُركَّب من متغيّرات. المفتاحُ القالبُ نفسُه، وفي العربيّة يُملأ كما هو.
- **ما لا يُمسّ**: نصٌّ خطُّه خطُّ المصحف (Amiri Quran / UthmanicHafs)، وما داخل `translate="no"`، وما تُرجم من قبل.
- **ترجمةُ المعاني** `data/tr/<رمز>/juz-XX.json` ‏(`"سورة:آية": "…"`)، تُجلب بدل `data/tafsir`، ومصدرُها في `trSrc`.

## إضافةُ لغة

1. `lang/<رمز>.js`: انسخ `ur.js` وترجم القيم. **المفاتيح لا تُمسّ.** والرموزُ في أوّل النصّ وآخره لا تُكتب.
2. في رأس `index.html` سطرٌ في `LANGS`: `xx:{n:'اسمُها بلغتها', dir:'rtl'|'ltr', ready:false, tr:true, trSrc:'…'}`.
   ما دامت `ready:false` فهي مخفيّةٌ من القائمة، وتُجرَّب بالرابط `?lang=xx`.
3. ترجمةُ المعاني من QuranEnc: `https://quranenc.com/api/v1/translation/sura/<key>/<رقم السورة>` لكلّ سورة،
   تُقسَّم أجزاءً بـ `JUZ_AT`، ويُحذف منها `[1]` إشاراتُ الحواشي. ورقمُ الإصدار من `/api/v1/translations/list/<رمز>`.
   **المعتمدُ ترجماتُ مركز رواد** (قرار صاحب التطبيق)، وما كان مثلَها في العقيدة.
   **قبل اعتماد أيّ ترجمة تُقارَن آياتُ الصفات فيها بالتفسير الميسّر**: 48:10 (اليد)، 5:64 (اليدان)،
   38:75 (بيديّ)، 20:5 (استوى = علا وارتفع)، 89:22 (وجاء ربك)، 55:27 (الوجه)، 67:16 (من في السماء = العلوّ)،
   54:14 (بأعيننا)، 3:54 (المكر). ما أوّل اليدَ بالقدرة أو المجيءَ بالأمر أو العلوَّ بالمُلك لا يُعتمد
   (كما رُدّت ترجمةُ باسميه الماليزيّة). وترجماتُ مجمع الملك فهد نفسِه لا توجد إلّا كتبَ PDF.
   عند التنزيل: إشاراتُ الحواشي `[1]` و«(৩)» البنغاليّة تُحذف؛ والأوزبكيّةُ كيريليّةٌ عند رواد
   فتُحوَّل إلى اللاتينيّة الرسميّة (oʻ gʻ بالحرف U+02BB).
   **شرطُ QuranEnc**: لا يُعدَّل النصّ، ويُذكر المصدرُ ورقمُ الإصدار.
4. `npm run i18n` حتى لا يبقى نقص، ثمّ `npm run i18n:live`، ثمّ `ready:true`.
5. **لغاتُ اليسار** (`dir:'ltr'`) مدعومة: `html[dir=ltr]` يقلب التخطيطَ المبنيَّ بخصائصَ منطقيّة (`inset-inline`،
   `margin-inline`)، والقرآنيُّ يبقى من اليمين بقاعدة `[dir=ltr] :is(.ayah,.chip,.opt,…){direction:rtl}`،
   والسحبُ بين التبويبات ينقلب (`SWIPE_SGN`)، والأسهمُ و«» في أوّل النصّ وآخره تنعكس في المحرّك (`flip`)،
   وسهمُ البطاقات `.gcgo` بـ`scaleX(-1)`، والأرقامُ ٠-٩ تصير 0-9، والتاريخُ بلغة الواجهة.
   **عنصرٌ قرآنيٌّ جديد بصنفٍ جديد يُضاف إلى تلك القاعدة**، وإلّا انقلبت كلماتُ الآية في لغات اليسار.
   ولكلّ لغة يسارٍ المفاتيحُ الزائدةُ في `en.js` (أسماءُ القرّاء لاتينيّةً، و«{s1} {0}»…) — يفحصها القسم ٦.
   ولغةٌ حروفُها خارج خطّ الواجهة (التركيّة ş ğ İ، البنغاليّة، الهوسا ɓ ɗ ƙ) تُضاف إلى قاعدة خطّ الجهاز
   `html:is([lang=tr],[lang=bn],[lang=ha],[lang=uz]) body{font-family:system-ui…}`.
6. **الشريطُ السفليّ كلمةٌ واحدة**: مسجدي ← «Mosque» لا «My mosque»، ومتجري ← «Store»، واسمي ← «Name» — وإلّا
   علا الشريطُ سطرين (ملاحظة صاحب التطبيق).
7. **الترجمةُ بالتوازي**: `ref_rows` (المفتاحُ العربيّ مع الإنجليزيّة مرجعاً) لكلّ وكيلٍ لغة، بقواعدَ صارمة (الخاناتُ
   والوسومُ كما هي، «←» تصير «→» في لغات اليسار، ما بُتر من «» يبقى مبتوراً)، ثمّ يُفحص آليّاً قبل الدمج.

## عند تعديل الشيفرة (مهمّ)

**تعديلُ نصٍّ عربيٍّ في الواجهة يُسقط ترجمتَه بصمت**، لأنّ النصَّ نفسَه هو المفتاح. فبعد كلِّ تعديلٍ لنصّ:

```
npm run i18n          # فحصٌ ثابت: الجديدُ بلا ترجمة، وصيغُ العدد، وقوالبُ tx()، والمفاتيحُ اليتيمة
```

- نصٌّ جديدٌ للواجهة ← أضفه إلى كلّ `lang/*.js`.
- ليس للواجهة (آية، اسم، جزءُ جملةٍ مترجَمةٍ كاملةً) ← `npm run i18n -- --accept` فيدخل `lang/i18n-ignore.json`.
- جملةٌ تُركَّب من متغيّرات ← `tx('… {x} …', {x})` بدل `'…'+x+'…'`، وأضف القالب إلى القواميس.
  **لا تُركَّب جملةٌ من قطعٍ عربيّة**: ترتيبُ الكلام يختلف بين اللغات فلا تُترجم القطعُ منفصلة.
- عددٌ مع معدود ← `arCount(n, C_XXX)`، ولكلّ `C_XXX` جديدةٍ `#1`/`#n` في كلّ قاموس.
- `innerHTML` لجملةٍ فيها `<b>`: مفتاحُها بالوسوم كما هي — والأسهلُ `tx()` بقالبٍ فيه الوسوم.

وللجملِ التي لا تظهر إلا بالتشغيل: `npm run i18n:live` (يحتاج `npm i --no-save playwright` وChrome) —
يضغط الأزرارَ مئاتِ المرّات ويجمع ما ظهر بالعربيّة.

## دروسٌ تعلّمناها

- **الترجمةُ لا تُحقن في قيمٍ يقرؤها المنطق**: لم يُوجد في الشيفرة ما يقارن نصّاً معروضاً (`textContent==='…'`)؛ فإن أُضيف كُسر بالترجمة.
- **ترجمةٌ تطابق مفتاحاً عربيّاً** تُترجم مرّتين (كان «الحفظ» ← «حفظ» الأرديّة، و«حفظ» مفتاحُ زرّ «حفظ»، فصار «محفوظ کریں»).
  المحرّكُ الآن لا يُعيد ما تُرجم، وأداةُ البناء تُنبّه إلى التصادم — لكن تُختار الترجمةُ بما لا يطابق مفتاحاً.
- **الحروفُ المشتركة**: الأرديّةُ بحروفٍ عربيّة، فيُميَّز المترجَمُ بحروفها الخاصّة (ٹ ڈ ڑ ک گ ں ھ ہ ۃ ی ے) وبقيم القاموس.
- **لا تبنِ حول عنصرٍ له معرِّف**: الجملةُ التي تُترجم كاملةً يُعاد بناؤها، فلا يُترجم هكذا ما فيه زرٌّ أو حقلٌ أو `id`.
- **المصطلحاتُ الأرديّة المعتمدة**: جزء = پارہ، مراجعة = دہرائی، تسميع = سنانا، مقطع = حصہ، سورة = سورت، وجه = صفحہ،
  شهادة = سند، الإعدادات = ترتیبات، والخطابُ بـ«آپ».
- **الترجمةُ بقلم آلة**: تحتاج مراجعةَ متحدّثٍ أصليٍّ قبل النشر الواسع.
